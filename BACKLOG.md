# Бэклог (Техдолг)

> Отсортировано по приоритету. Задачи без галочки — в очереди.

## 🔴 Высокий приоритет

### 1. История спреда — полный месяц
- **Суть:** Сейчас график подгружает ~7 дней (после фикса производительности). Нужно, чтобы mean/stddev/Z-Score считались за **полный месяц** (~30 дней), а график отображал нужный range.
- **Сложность:** Средняя. Потребуется разделить «данные для графика» (7 дней) и «данные для статистики» (30 дней), либо увеличить лимит.
- **Статус:** 📋 Не начато

## 🟡 Средний приоритет

### 2. Funding Rates (Hyperliquid)
- **Суть:** KPI-карточка + модальное окно с историей фандингов из Hyperliquid `fundingHistory`.
- **Формат:** Вариант В (согласован ранее): карточка на главном экране с текущим 8h rate, annualized %, 24h accumulated % и sparkline. По клику — модалка с полным графиком и таблицей.
- **Сложность:** Средняя. Новый endpoint `/api/funding/{contract_id}`, таблица `funding_history` в БД, фронтенд.
- **Статус:** ⏸️ Отложено

### 3. Telegram-бот (сигналы Z-Score)
- **Суть:** Автоотправка сигналов при |Z-Score| > 2.0. Текст + скриншот графика.
- **Сложность:** Средняя. Bot API, webhook, рендер графика.
- **Статус:** 📋 Не начато

### 4. Paper Trade (симулятор)
- **Суть:** Симуляция сделок по сигналам дашборда. Виртуальный портфель, P&L, история сделок.
- **Сложность:** Средняя. Новая таблица `trades`, логика входа/выхода, фронтенд-вкладка.
- **Статус:** 📋 Не начато

### 5. WebSocket вместо polling
- **Суть:** Замена HTTP-polling на WebSocket для real-time обновления цен и графика.
- **Сложность:** Средняя. FastAPI WebSocket endpoint, обновление фронтенда.
- **Статус:** 📋 Не начато
