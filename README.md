# Brent Spread Dashboard — BMK + BMR

Дашборд для арбитражного спред-трейдинга между фьючерсом **Brent mini (BMK6/BMM6)** на **MOEX** и перечным **BRENT** на **Hyperliquid**.

---

## Стратегия

Спред-трейдинг на основе **Z-Score** — статистический арбитраж, который использует отклонение спреда от среднего значения.

### Суть

1. **Загрузи историю** — посмотри Avg (среднее) и σ (стандартное отклонение).
2. **Жди сигнала** — Z-Score > 2.0 или < -2.0.
3. **Вход** — открой спред-позицию:
   - **Z < -2** → спред сильно отрицательный (HL дешевле MOEX) → **купи HL + продай MOEX**
   - **Z > 2** → спред сильно положительный (HL дороже MOEX) → **продай HL + купи MOEX**
4. **Тейк-профит** — Z вернулся к 0 (спред = среднему).
5. **Стоп-лосс** — Z дошёл до ±3σ (движение пошло против тебя).

### Метрики дашборда

| Метрика | Описание |
|---------|----------|
| **MOEX** | Текущая цена фьючерса Brent mini на MOEX (USD/bbl) через **Alor API**. Торговые часы: 10:00–23:50 МСК. |
| **HL BRENTOIL** | Текущая цена перечного Brent на Hyperliquid (USD). Торгуется 24/7. |
| **Spread (mid, %)** | Разница mid-price: HL − MOEX в процентах. |
| **Prices** | Сырые цены MOEX и HL на одном графике для визуального сравнения. |
| **Arb Spread** | Реальный исполнимый спред через bid/ask с учётом проскальзывания. |
| **Z-Score (live)** | Текущее отклонение спреда от среднего в единицах σ. |
| **Median** | Медиана спреда. Более устойчива к выбросам, чем среднее. |
| **Min / Max** | Исторические экстремумы спреда за период (20 дней). |
| **Точка входа (±2σ)** | Ключевая метрика: нижняя и верхняя границы коридора для входа в сделку. |

### Сигналы Z-Score

| Z-Score | Интерпретация |
|---------|---------------|
| \|Z\| < 1.0 | Норма, без сигнала — жди. |
| 1.0 ≤ \|Z\| < 1.5 | Небольшое отклонение, наблюдай. |
| 1.5 ≤ \|Z\| < 2.0 | Повышенное отклонение, готовься к входу. |
| \|Z\| ≥ 2.0 | **Аномалия — точка входа!** |

## Запуск

### Требования

- Python 3.11+
- Установленные пакеты: `fastapi`, `uvicorn`, `httpx`, `python-dotenv`
- **Alor Refresh Token** (в файле `backend/.env`)

### Переменные окружения

Создай файл `backend/.env`:

```env
ALOR_REFRESH_TOKEN=your_alor_refresh_token
ALOR_PORTFOLIO=your_portfolio_id
```

### Запуск сервера

```bash
cd backend
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

### Открытие дашборда

```
http://127.0.0.1:8000
```

> **Важно:** на Windows используй `127.0.0.1` вместо `localhost`, иначе каждый запрос к API будет задерживаться на ~2 секунды из-за IPv6 fallback.

## Контракты

По умолчанию дашборд работает с двумя контрактами:

- **BMK6** — `BMK6` (MOEX) / `xyz:BRENTOIL` (Hyperliquid)
- **BMM6** — `BMM6` (MOEX) / `xyz:BRENTOIL` (Hyperliquid)

Можно добавить новые контракты через кнопку «+ Добавить» в шапке.
