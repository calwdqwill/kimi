MOEX — текущая цена фьючерса Brent mini на MOEX в USD/bbl. Торгуется 10:00–23:50 МСК.

HL BRENTOIL — текущая цена перечного Brent на Hyperliquid в USD. Торгуется 24/7.

USDT/RUB — курс х. Справочная информация, не влияет на расчёт спреда (обе цены уже в USD).
•
Spread — объединённый блок. Mid: разница mid-price HL – MOEX. Arb: реальный исполнимый спред через bid/ask с учётом проскальзывания.
СТАТИСТИКА — ТОЧКА ВХОДА
•
Avg Spread % — среднее значение спреда за весь период. Это центр гравитации — спред стремится сюда возвращаться.
•
Median — медиана. Более устойчива к выбросам. Если сильно отличается от Avg — есть перекос.
•
StdDev (σ) — стандартное отклонение. Ширина «нормального» коридора. 68% времени спред живёт в пределах Avg ± 1σ.
•
Z-Score (Live) + Точка входа (±2σ) — объединённый блок. Z-Score показывает, сколько σ текущий спред отстоит от среднего.
|Z| < 1.0 — норма. |Z| 1.5–2.0 — повышенное отклонение. |Z| > 2.0 — аномалия, точка входа!
Нижняя граница: спред раздулся → купи HL + продай MOEX → жди возврата к среднему.
Верхняя граница: спред сжался → продай HL + купи MOEX → жди возврата к среднему.
•
Min / Max — исторические экстремумы спреда за период.
ГРАФИКИ
•
Spread % — процентный спред с полосами Mean и ±2σ (Боллинджер). Выход за красный пунктир = сигнал.
•
Prices — обе цены на одном графике для визуального сравнения.
•
Z-Score — нормализованный спред. Пересечение нулевой линии = возврат. Возврат к 0 = сигнал.
СТРАТЕГИЯ

1. Загрузи историю — посмотри Avg и σ.

2. Жди Z-Score > 2.0 или < -2.0.

3. Вход: открой спред-позицию (лонг дешёвую ногу, шорт дорогую).

4. Тейк: Z вернулся к 0 (спред = среднему).

5. Стоп: Z дошёл до ±3σ (против тебя).
